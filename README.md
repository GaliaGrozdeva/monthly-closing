# Месечно приключване

Библиотека за счетоводни процедури, организирани по категории и етикети.
Python 3.13, Django 6.1.3 и SQLite. Интерфейсът е на български.

## Възможности

- Добавяне, корекция и изтриване на категории, процедури и етикети.
- Търсене в заглавия и инструкции, филтриране и сортиране.
- Брой номерирани стъпки чрез собствения template filter `count_steps`.
- Проверки на въведените данни и потвърждение при изтриване.

## Структура

`categories` — категории; `procedures` — инструкции и търсене; `tags` — етикети.
Всяка процедура има една категория и може да има няколко етикета.
`config` съдържа настройките; `templates` и `static` — интерфейса.

## Стартиране на Windows

Необходим е инсталиран Python 3.13.

```powershell
git clone https://github.com/GaliaGrozdeva/monthly-closing.git
cd monthly-closing
.\setup.bat
.\start.bat
```

`setup.bat` подготвя средата и базата при първа инсталация.
След това приложението се стартира със `start.bat`.
Адрес: <http://127.0.0.1:8000/>. Спиране: Ctrl+C в терминала.

Не са нужни профил, пароли или променливи на средата за локално стартиране.
По желание: `DJANGO_SECRET_KEY` заменя локалния ключ, а `DJANGO_DEBUG=0`
изключва debug режима и показва собствената 404 страница.

## Клавиши

**F1** — нов запис; **F2** — запазване; **F3** — търсене;
**Alt+E** — корекция; **Alt+D** — потвърждение за изтриване;
**Esc** — отказ или връщане. В списъка с процедури Esc изчиства филтрите.

## Примерни данни

По желание, след първоначалната подготовка и само в празна база:

```powershell
.\.venv\Scripts\python.exe manage.py loaddata fixtures/monthly_closing_procedures.json
```

Файлът съдържа 6 категории, 12 процедури и 4 етикета.
Зареждането в използвана база може да презапише записи.

## Проверки

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
.\.venv\Scripts\python.exe manage.py test
```

Тестовете използват отделна временна база.
Работните данни са в `db.sqlite3`, който не се включва в Git.
Настройките на приложението са за локална работа.
